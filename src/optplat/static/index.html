                        Options tracker

                        What the tracker has found

                        Features known when a contract was flagged that came before a better or worse result than the average flagged contract. Only groups with enough marks appear.

                          What happened after contracts were flagged

                          Each flagged contract is bought at its ask on the flag day and sold at its bid on the mark day, so the spread is already paid and losing on average is the expected starting point. The underlying's move counts in the direction that helps the contract: up for a call, down for a put.

                          Which features came first

                          Each row is a group of flagged contracts that shared one feature, compared with all flagged contracts at the same mark.

                          Contracts being watched

                          Flagged in the last 12 days. Marks fill in as later scans read each contract again.

                          What counts as unusual

                          The rules the scanner applies today. They are experiment settings; this page is how they get tested.

                                Settings

                                The watchlist holds up to 20 names. SPY and QQQ are index funds; single stocks add earnings dates (the events agent opposes entries around them), wider spreads (the risk limits may refuse more of them) and one option chain read per name each cycle. "Add to watchlist" fills the box with the sector's most traded names from the latest scan; nothing changes until you choose Save settings. Risk limits are not affected.
